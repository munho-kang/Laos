The rhythm — all day today

ONE feature→ TELL→ CHECK→ SAVE→ next
pick ONE MUST feature say what you want test in the browser Save Point + ✔ in your log next feature

Save Point

🎮💾

Save your game

copy index.html → index-v1.html

After every working feature: make a copy in the file explorer.
Next time: index-v2.html, index-v3.html…

Like saving before a boss fight — if everything breaks, you go back to your last save.

Escape Move ① — when you are stuck

📋 Paste the error

Red error? Strange message? Copy ALL of it, then:

I got this error. Please fix it: (paste the error here)

An error is not bad news — it is the best hint you can give the AI.

Escape Move ② — when you are stuck

⏪ /undo = time machine

The last change made things worse?

/undo

It goes back one step. Repeat if needed.

Your best friend when the AI changed too many things.

Escape Move ③ — when you are stuck

✂️ Ask smaller

🐘 Too big

  • "Add a full expense tracker."

🐜 Small — works!

  • "Add ONE input box and a button that adds the number to a list."

If one big ask does not work — cut it into pieces. Ask for piece 1 only.

Escape Move ④ — when you are stuck

🔄 Fresh start

Conversation totally confused? Reset the AI's memory:
new session with Ctrl+X, then N — and send the restart prompt:

Look at my file index.html. It is a ___ app. It already does: ___. Now I want to add ONE thing: ___. Do not change anything else.

Cheat sheet no. 5 — your file stays, only the chat restarts.
