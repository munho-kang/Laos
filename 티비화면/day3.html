The secret

Every app = a list of small features

🍜 Food Menu App =

  1. User can see menu items with prices
  2. User can filter by category
  3. User can see the total

It looks like magic. It is just 3 small features.

The feature sentence

One feature = one sentence

"User can ______."

❌ Too big

  • "User can do everything about food"

✅ Just right

  • "User can see 10 menu items with prices."

Can't say it in one sentence? Then it is a wish, not a feature.

How many features?

MUST 3 + NICE 2

  • MUST ×3 — my app needs these (Friday demo!)
  • NICE ×2 — extra, only if there is time
Small and FINISHED beats big and broken.

Only 2 build days left — that is why we cut.

Capstone rules

The rules 📏

  • 📄 ONE file: index.html — that is the whole app
  • 🚫 No server · no login · no external API
  • ✅ Saving data in the browser (localStorage) is OK
  • 🎤 Friday: 2-minute demo

Theme gallery

Pick your theme

  • 🏞️ Hometown travel guide — places, photos, best route
  • 🍜 Lao food menu — menu + prices, filter, total
  • 🎭 Club / department page — intro, members, join
  • 🇱🇦 Laos quiz — question, answer, score
  • 💰 Pocket money tracker — income/expense, balance
  • 🃏 English–Lao flashcards — flip, meaning, known words

…or your own idea (within the rules!) — pick what your family or friends could actually use.
