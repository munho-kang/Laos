Golden Rule 1

Be specific

❌ Vague

  • "Make a game."
  • "Make it nice."
  • AI has to guess → random result

✅ Specific

  • What: a number guessing game
  • How it works: 1 to 100 · 7 tries · "higher / lower"
  • How it looks: colorful, big buttons

Say what + how it looks + how it works.

Anatomy of a good prompt

3 parts: WHAT + RULES + LOOKS

Create index.html — a number guessing game. The computer picks a secret number from 1 to 100. I type a guess. The game tells me "higher" or "lower". I have 7 tries. Show a win or lose message at the end. Make it colorful with big buttons.

WHAT to build · RULES of the game · how it LOOKS

Golden Rule 2

One thing at a time

❌ Everything at once

  • "Add a Play Again button and emoji and a win counter and change all the colors and…"
  • Too much → AI gets confused, YOU cannot check

✅ One by one

  • "Add a Play Again button." → CHECK
  • "Add emoji 🎉 when I win." → CHECK
  • Small asks, many rounds

Don't panic

3 safety tools 🛟

  • Esc — STOP. AI going the wrong way? Stop it now.
  • /undo — Time machine. Undo the last change. Repeat if needed.
  • Ctrl+X, then N — Fresh start. New session, clean conversation.

You can always go back. Nothing is broken forever.
