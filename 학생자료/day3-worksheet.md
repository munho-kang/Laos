## Step 2 — Plan mode: talk first, build later (15 min)

- ☐ Make a new folder on the Desktop. Name it: `my-app`
- ☐ Open the terminal **in that folder** → type `opencode` and press Enter
- ☐ Press **Tab** → check the **bottom-right corner**: it says **Plan**

> In **Plan** mode the AI **talks** with you — it does **NOT** build files.
> Perfect for checking your plan.

3. User can ___

## Step 3 — Back to Build: make v0 (35 min)

- ☐ **Press Tab again!** Bottom-right shows **Build** — now the AI builds files
- ☐ I have my teacher's signature (no? → call the teacher first)

v0 = title + layout + MUST feature 1 only. Type:

```text
Create index.html for my app "___" (app name).
Layout: the app name as a big title at the top, and my name "___" under it.
Now add ONLY MUST feature 1: User can ___.
Do not add other features yet. Keep it simple.
```

- ☐ **CHECK** — open `my-app/index.html` in the browser
- ☐ **FIX** 1–2 times if needed (*what I SEE + what I WANT*)

**A good v0 today = the title shows + feature 1 works. Ugly is OK — we make it pretty on Friday!**
