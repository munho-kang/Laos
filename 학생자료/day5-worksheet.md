## Step 1 — Polish sprint (45 min)

Work in THIS order. Start at ① — do not jump to ④!

- ☐ **① Finish remaining MUST** — your Definition of Done comes first
- ☐ **② Bug hunt** — test everything like a first-time user: click every button, try every screen
- ☐ **③ Polish** — clean title, nice colors, add a footer
- ☐ **④ NICE** — only if time is left

Found a bug? Use the FIX formula: **what I SEE + what I WANT**.
