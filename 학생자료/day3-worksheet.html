💡 Day 3 — My App Plan

Mission: Turn YOUR idea into a plan — then build v0 (your first screen).

Name:

Big news: from today you build YOUR own app — and you present it on Friday! 🎉
The loop never changes: TELL (say it) → WATCH (AI builds) → CHECK (browser) → FIX (say the change)

📏 Capstone rules (read me first!)

- ONE file only: index.html — that is the whole app
- No server, no login, no external API
- Saving data in the browser (localStorage) is OK ✅
- Friday: 2-minute demo in front of everyone 🎤

🗂️ Themes — pick one (or your own idea, within the rules)

Tip: pick something your family or friends could actually use.

Step 2 — Plan mode: talk first, build later (15 min)

  • Make a new folder on the Desktop. Name it: my-app
  • Open the terminal in that folder → type opencode and press Enter
  • Press Tab → check the bottom-right corner: it says Plan

In Plan mode the AI talks with you — it does NOT build files.
Perfect for checking your plan.

Type this (copy your plan from Step 1):

I want to build ___ (app name) for ___ (who).
It is ONE file: index.html. No server, no login.
MUST features:
1. User can ___
2. User can ___
3. User can ___
Is this a good plan for 2 days? What should I build first?

AI's advice — what to build first, what to be careful about:

⚠️ The AI loves to add MORE features. Golden Rule 3: You decide, AI builds.
Keep MUST = 3. Extra ideas go to NICE.

  • Show your plan to the teacher → get the signature in Step 1

Step 3 — Back to Build: make v0 (35 min)

  • Press Tab again! Bottom-right shows Build — now the AI builds files
  • I have my teacher's signature (no? → call the teacher first)

v0 = title + layout + MUST feature 1 only. Type:

Create index.html for my app "___" (app name).
Layout: the app name as a big title at the top, and my name "___" under it.
Now add ONLY MUST feature 1: User can ___.
Do not add other features yet. Keep it simple.
  • CHECK — open my-app/index.html in the browser
  • FIX 1–2 times if needed (what I SEE + what I WANT)

A good v0 today = the title shows + feature 1 works. Ugly is OK — we make it pretty on Friday!

💪 Stretch (if v0 already works)

  • Start MUST feature 2 — remember: ONE request at a time
  • Ask the AI: Which of my 3 MUST features is the hardest? Why? Answer simply.
