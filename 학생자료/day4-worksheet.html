The sprint rhythm (repeat all day):
ONE feature → TELL → CHECK → Save Point → ✔ → next

4 Escape Moves (when you are stuck):
① Copy & paste the error ② /undo ③ Ask smaller ④ Fresh start: Ctrl+X, then N + restart prompt

① Error prompt — copy ALL of the error message, then:

I got this error. Please fix it:
(paste the error here)

④ Restart prompt (new session — Ctrl+X, then N):

Look at my file index.html.
It is a ___ app. It already does: ___.
Now I want to add ONE thing: ___.
Do not change anything else.

💾 Save Point — after EVERY working feature

When a feature works, make a backup in the file explorer:

  • Copy index.html → name the copy index-v1.html (next time: index-v2.html, index-v3.html…)

Like saving your game before a boss fight. 🎮 If everything breaks, you can always go back to your last save.
