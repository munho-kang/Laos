🎮 Day 2 — Talking to AI Like a Pro

Mission: Build a number guessing game — and see why your WORDS matter.

Name:

The Loop (remember these 4 words!):
TELL (say what you want) → WATCH (AI builds) → CHECK (open in browser) → FIX (say what to change)

Step 1 — The vague experiment (10 min)

Today we start the WRONG way — on purpose. 😉

  • Make a new folder on the Desktop. Name it: number-game
  • Open the terminal in that folder
  • Type opencode and press Enter
  • Send exactly this prompt — nothing more:
Make a game.

WATCH what the AI does. Then fill in this table:

QuestionYour answer
What did the AI make?
What did YOU want?
Same or different? Same / Different

Did the AI ask you a question back ("What kind of game?")?
Do not answer it. Write it in the table — it means the AI did not have enough information!

Done early? Compare with your neighbor. Different results from the same prompt? That is the point!

Step 2 — New session + specific prompt (10 min)

  • Start a new session: press Ctrl+X, then N
  • Fill in the blanks ___, then send this prompt:
Create index.html — a number guessing game.
The computer picks a secret number from ___ to ___.
I type a guess. The game tells me "higher" or "lower".
I have ___ tries. Show a win or lose message at the end.
Make it colorful with big buttons. Use the color ___.

(Example: from 1 to 100 · 7 tries · color blue)

CHECK:

  • Open the folder number-game → double-click index.html
  • Play your game 2 or 3 times
  • Raise your hand when your game works! 🎉

Same AI as Step 1. Only your words changed.
Golden Rule 1: Be specific.

Step 3 — FIX rounds (45 min)

Ask for changes — ONE at a time (Golden Rule 2!). After each change, refresh the browser (F5) and CHECK. Do at least 3:

✔FIX ideaExample prompt
Show tries leftShow how many tries I have left, big and clear.
Colors + emojiAdd fun emoji 🎯🎉 and change the colors to ___ and ___.
Play Again buttonAdd a "Play Again" button so I can restart without refreshing the page.
Win counterCount how many games I win. Show the number at the top.

💪 Stretch (if you finish early)

  • Save my best score (fewest tries) so it is still there after I close the browser.
  • Add difficulty levels: Easy (1 to 50) and Hard (1 to 500). Let me choose before the game starts.

🛟 Safety tools (keep this box in mind!)

ToolWhat it does
EscStop — the AI stops right now
/undoUndo the last change (you can repeat it)
Ctrl+X, then NNew session — a fresh start
