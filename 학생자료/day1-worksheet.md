# 🌟 Day 1 — My First Webpage

**Mission: Build a webpage about YOU — by talking to AI.**

Name: ______________________

> The Loop (remember these 4 words!):
> **TELL** (say what you want) → **WATCH** (AI builds) → **CHECK** (open in browser) → **FIX** (say what to change)

## Step 1 — Get ready (5 min)

- ☐ Make a new folder on the Desktop. Name it: `my-profile`
- ☐ Open the terminal **in that folder**
- ☐ Type `opencode` and press Enter

You should see the opencode screen. Ready!

## Step 2 — TELL: your first prompt (10 min)

Fill in the blanks, then type this prompt into opencode (copy it exactly — fill your own words in the `___`):

```text
Create index.html — a personal profile page about me.
My name is ___.
I study ___ at ___ university.
Add these sections: About Me, My Hobbies, My Dream.
Use a nice modern design with the color ___.
```

Now **WATCH**. The AI is writing HTML, CSS and JavaScript for you.
(It can take 1–2 minutes. That is normal.)

## Step 3 — CHECK: open your page (10 min)

- ☐ Open the folder `my-profile` in the file explorer
- ☐ Double-click `index.html` → it opens in the browser
- ☐ **You are looking at your first webpage!** 🎉

Raise your hand when you see your page.

## Step 4 — FIX: make it YOURS (40 min)

Pick from this menu (or invent your own). Do **at least 3**:

| ✔ | FIX idea | Example prompt |
|---|---|---|
| ☐ | Change colors | `Change the colors to ___ and ___.` |
| ☐ | Add emoji | `Add a big emoji 😄 next to my name.` |
| ☐ | Add a list | `Add a section "My Favorite Songs" with 3 songs: ___, ___, ___.` |
| ☐ | Bigger title | `Make the title bigger and center it.` |
| ☐ | Add a fun button | `Add a button that shows a surprise message when clicked.` |
| ☐ | Phone friendly | `Make it look good on a phone screen.` |
