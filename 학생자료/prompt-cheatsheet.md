# 🗣️ Prompt Cheat Sheet — Talk to AI in English

Keep this next to you every day. Copy a template, fill in the blanks `___`, send it.

> **Don't worry about grammar.** Short sentences are fine. Wrong grammar is fine.
> The AI understands you. Just be **specific**.

---

## 1. 🚀 Start something new

```text
Create index.html — a ___ (webpage / game / app) about ___.
It should have: ___, ___, and ___.
Make it look modern and colorful.
```

```text
Create a simple web app in ONE file (index.html).
The app is for ___ (who will use it).
Main feature: the user can ___.
```

## 2. 🎨 Change how it looks

```text
Change the colors to ___ (blue and white / dark theme / warm colors).
```

```text
Make the title bigger and center it.
```

```text
Add an emoji ___ next to the heading.
```

```text
Make it look better on a phone screen.
```

## 3. ➕ Add ONE feature

> Golden Rule: **one thing at a time.**

```text
Add a button that ___ (shows a message / clears the list / starts again).
```

```text
Add a score. Start at 0. Add 1 point when the user ___.
```

```text
Save the data so it is still there after I close the browser.
```

## 4. 🔧 Fix a problem

**Formula: what I SEE + what I WANT.**

```text
When I click ___, nothing happens.
I want it to ___.
Please fix it.
```

```text
The page shows ___ but it should show ___.
```

**If you see an error message → copy ALL of it, then:**

```text
I got this error. Please fix it:
(paste the error here)
```

## 5. 😵 When you are stuck

| Situation | Do this |
|---|---|
| AI changed too many things | Type `/undo` — it goes back one step. Repeat if needed |
| AI is going the wrong way | Press **Esc** to stop it, then explain again |
| Everything is confusing now | Start a **new session** (Ctrl+X, then N) and use the restart prompt below |
| The request feels too big | Cut it into smaller pieces. Ask for piece 1 only |

**Restart prompt (new session):**

```text
Look at my file index.html.
It is a ___ app. It already does: ___.
Now I want to add ONE thing: ___.
Do not change anything else.
```

## ⭐ The 3 Golden Rules

1. **Be specific** — what it is, how it looks, what it does.
2. **One thing at a time** — small asks, many rounds.
3. **You decide, AI builds** — always CHECK in the browser. You are the boss.
